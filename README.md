## Bu Nedir?

Bu yazılım, sıradan bir kedinin "miyav" demesini alıp, onu **epik Türkçe şiirlere**, **derin hayat tavsiyelerine** ve **kader kehanetlerine** çeviren, insanlık tarihinin en önemli bilimsel atılımlarından biridir.

NASA, CERN, hatta komşunun kedisi bile bu projeyi yakından takip ediyor.  
Bazıları "Bu sadece rastgele string seçiyor" diyor.  
Biz diyoruz ki: **"Siz miyavın derinliğini anlamıyorsunuz."**

## Özellikler

- 🔍 Gelişmiş frekans tarama motoru (1.5 saniye sürüyor, abarttık)
- 🧠 Sinir ağı simülasyonu (aslında `random.choice`)
- 📜 5 farklı epik şiir şablonu
- 💡 5 hayat değiştiren tavsiye
- 🔮 5 kader kehaneti (gerçek olma ihtimali %0.0001)
- %99.99 doğruluk oranı (geri kalan %0.01 kedilerin gizli tuttuğu kısım)

## Kurulum

```bash
git clone https://github.com/Tentivory/abartili-miyav-cevirmeni.git
cd abartili-miyav-cevirmeni
python3 miyav_cevirmeni.py
```

Veya doğrudan:

```bash
python3 miyav_cevirmeni.py "miyav miyav"
```
